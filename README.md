<h1 align="center">서로지킴 (CallGuard)</h1>

<p align="center">
  통화가 길어지면 <b>본인에게 먼저 경고</b>하고, <b>보호자에게 문자</b>로 알려주는<br>
  보이스피싱 예방 보조 앱 (Android)
</p>

---

## ⚠️ 먼저 읽어주세요

- 이 앱은 **보이스피싱을 막아주는 앱이 아니라, 위험 신호를 알려주는 보조 도구**입니다.
  경고가 없었다고 해서 안전하다는 뜻이 아니며, 경고가 떴다고 해서 반드시 범죄라는 뜻도 아닙니다.
- **통화 내용을 녹음하거나 듣지 않습니다.** 오직 "통화가 얼마나 오래 이어졌는지"만 봅니다.
- 어떤 금융기관·수사기관·통신사와도 관계가 없는 개인 프로젝트입니다.
- **이 앱은 이 저장소의 [Releases](../../releases)에서만 받으세요.**
  전화나 문자로 받은 링크의 APK 파일은 설치하지 마세요. 그런 방식이 바로 보이스피싱 수법입니다.

## 어떻게 동작하나요?

통화가 시작되면 타이머가 돌고, 정해둔 시간에 단계별로 알립니다. (시간은 앱에서 바꿀 수 있습니다)

| 단계 | 기본 시간 | 동작 |
|---|---|---|
| 1차 | 통화 8분 | 강한 진동("징징") + 알림 — **본인에게만** |
| 2차 | 통화 10분 | 전체 화면 경고 + 강한 진동·경고음 + **보호자 전원에게 문자 발송** |
| 통화 종료 | - | 예약된 경고를 모두 취소 (통화 화면 위에 떠 있던 경고도 닫힘) |

경고 화면에서는 두 가지를 할 수 있습니다.

- **지금 바로 전화 끊기** — 통화 화면으로 이동합니다. (앱이 직접 전화를 끊지는 않으며, 종료 버튼은 직접 누르셔야 합니다)
- **경고 해제** — 아는 사람과의 통화라면 보호자에게 "안심하세요" 문자를 보냅니다.

보호자 번호와 "예외 번호"(자주 통화하는 가족·지인)로 오는 통화는 감시하지 않습니다.

## 설치 방법

Android 8.0(Oreo) 이상이 필요합니다.

1. 이 저장소의 **[Releases](../../releases)** 에서 최신 버전의 `app-release.apk` 를 내려받습니다.
2. (선택, 권장) 파일이 원본인지 확인합니다. 릴리스 노트에 적힌 SHA-256 값과 비교하세요.
   - Windows: `certutil -hashfile app-release.apk SHA256`
   - Mac / Linux: `shasum -a 256 app-release.apk`
3. 내려받은 APK 를 엽니다. 스토어 앱이 아니어서 **아래와 같은 안내가 나올 수 있습니다.** (기기·Android 버전에 따라 문구는 조금씩 다릅니다)

   | 나타나는 화면 | 하는 일 |
   |---|---|
   | "이 출처의 앱 설치를 허용하시겠습니까?" | 사용 중인 브라우저/파일 앱에 대해 **이 출처 허용**을 켭니다. |
   | 삼성 갤럭시: **보안 위험 자동 차단**이 앱 설치를 막음 | `설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단` 에서 **설치하는 동안만** 끄고, 설치 후 다시 켭니다. |
   | Google Play 프로텍트: "알 수 없는 앱" 검사 안내 | 안내에 따라 진행합니다. (개발자가 스토어에 등록된 곳이 아니라서 나타납니다) |

4. 설치가 끝나면 **1단계에서 허용한 "출처 허용"과 3단계에서 끈 보안 기능을 원래대로 되돌리세요.**
5. 부모님 폰이라면 **자녀가 대신 설치하고 설정해 드리는 것**을 권장합니다.

> 설치 중 **"악성 앱으로 의심 — 설치할 수 없습니다"** 처럼 끌 수 없는 차단 화면이 나오면, 이 앱이 통화 기록·문자 발송 같은
> 보이스피싱 앱과 비슷한 권한을 쓰기 때문일 수 있습니다. 기기 이름·Android 버전과 함께 [Issues](../../issues)에 알려주세요.

## 처음 설정하기

앱을 열고 위에서부터 채웁니다.

1. **내 이름**, **1차·2차 시간**, **보호자 번호(최대 3명)**, **예외 번호**를 입력합니다.
2. 화면 아래의 권한 버튼 4개를 눌러 허용합니다. (권한 상태가 `[O]` 가 되면 완료)
   - ① 다른 앱 위에 표시 — 통화 중 경고 화면을 바로 띄우려면 필요합니다.
   - ② 알람 및 리마인더 — 정확한 시각에 경고하려면 필요합니다.
   - ③ 배터리 최적화 해제 — 절전 기능이 앱을 멈추지 않게 합니다.
   - ④ 통화 기록 권한 — 통화 상대 번호를 읽어 보호자·예외 번호를 감시에서 빼려면 필요합니다.
3. **저장하고 시작하기** 를 누릅니다.
4. **경고 화면 테스트**, **문자 테스트** 버튼으로 실제로 동작하는지 꼭 한 번 확인하세요.

## 앱이 요청하는 권한과 이유

| 권한 | 왜 필요한가요? |
|---|---|
| 전화 상태 (`READ_PHONE_STATE`) | 통화가 시작·종료되었는지 알기 위해 |
| 통화 기록 (`READ_CALL_LOG`) | 걸려온 전화의 상대 번호를 알아 보호자·예외 번호를 제외하기 위해 |
| 문자 발송 (`SEND_SMS`) | 보호자에게 경고·안심 문자를 보내기 위해 |
| 알림 (`POST_NOTIFICATIONS`) | 경고 알림을 표시하기 위해 |
| 다른 앱 위에 표시 (`SYSTEM_ALERT_WINDOW`) | 통화 화면 위에 경고를 즉시 띄우기 위해 |
| 정확한 알람 (`SCHEDULE_EXACT_ALARM`, `USE_EXACT_ALARM`) | 설정한 시간에 정확히 경고하기 위해 |
| 전체 화면 알림 (`USE_FULL_SCREEN_INTENT`) | 잠금 화면에서도 경고 화면을 띄우기 위해 |
| 진동 (`VIBRATE`) | 경고 진동을 울리기 위해 |
| 부팅 완료 (`RECEIVE_BOOT_COMPLETED`) | 재부팅 후 통화 상태를 초기화하기 위해 |
| 화면 켜짐 유지 (`WAKE_LOCK`) | 경고 시 화면을 켜기 위해 |

이 앱에는 **인터넷 권한이 없습니다.** 서버로 데이터를 보낼 수 없는 구조입니다. 자세한 내용은 **[개인정보 처리방침](PRIVACY.md)** 을 보세요.

## 알려진 한계

- **통화 시간만** 기준으로 합니다. 통화 내용이나 상대가 누구인지 판단하지 않습니다.
- **내가 건 전화**는 상대 번호를 알 수 없어(발신 번호 권한을 쓰지 않습니다) 감시 대상에 포함됩니다.
  보호자에게 건 전화도 오래 통화하면 경고가 뜰 수 있습니다.
- 문자는 "발송을 요청"하는 것까지만 확인합니다. 상대에게 실제로 도착했는지는 알 수 없습니다. (통신사 문자 요금이 부과될 수 있습니다)
  발송 자체가 실패하면 알림으로 알려드립니다.
- 제조사의 절전 기능이 강한 기기에서는 경고가 늦거나 빠질 수 있습니다. 위 설정의 ③번을 꼭 해주세요.
- Android 14 이상에서 **잠금 화면** 경고를 쓰려면 `설정 → 앱 → 특별한 접근 → 전체 화면 알림` 허용이 필요할 수 있습니다.
- 일부 기기에서는 설치가 막힐 수 있습니다. (위 설치 방법 참고)

## 소스에서 직접 빌드하기

- **Android Studio** 에서 이 폴더를 열고 실행하거나, `gradle assembleDebug` 로 디버그 APK 를 만듭니다.
- **GitHub Actions**(`.github/workflows/build-apk.yml`)가 푸시할 때마다 디버그 APK 를 만들고,
  서명 시크릿(`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`)이 있으면 서명된 릴리스 APK 도 만듭니다.
- 릴리스 서명 키는 **절대 저장소에 올리지 마세요.** (`.gitignore` 에 `*.keystore` 가 등록되어 있습니다)
